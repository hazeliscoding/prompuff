# Prompuff brand

- `mark.svg`: Puff on its own, transparent background. Use for favicons, avatars and small spots.
- `app-icon.svg`: 512×512 app tile. Source for `src/Prompuff.App/Assets/prompuff.ico`, `prompuff.png` and `prompuff-256.png`.
- `lockup.svg` / `lockup-dark.svg`: Puff plus the "Prompuff" wordmark (Manrope Bold, outlined) for light and dark backgrounds.
- Palette: charcoal `#0A0C10` / `#151920`, lavender `#B48EFF`, teal accent `#2DD4BF`, dusty pink `#E879A9`, peach `#E08E4A`, sky `#38BDF8`.
- Fonts: Manrope for UI, IBM Plex Mono for data and code (both OFL, see `licenses/`).
- Puff is a lavender cloud; never recolor it with the teal accent.

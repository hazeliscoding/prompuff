# Prompt

You are documenting a component for the {{project_name}} design system.

Component: {{component}}

Write: purpose (one sentence), anatomy, variants, states (default, hover, focus, disabled, loading), tokens used, accessibility notes, and three do/don't rules. Match the voice of the existing docs: precise, calm, no marketing adjectives.

# Notes

The explicit state list is what makes the output consistent across components.

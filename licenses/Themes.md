# Theme palettes

Prompuff's themes in Settings › Appearance use the colors of these palettes. Prompuff Dark and Prompuff Light are Prompuff's own. Where a palette has no color for one of Prompuff's roles, the closest color from the same palette fills in, and a few text colors are adjusted so text stays readable (WCAG AA). The palettes' authors don't endorse Prompuff.
